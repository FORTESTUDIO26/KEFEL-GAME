# הסטודיו של ליאורי

## ארבעה חדרים וטריקים לזכירה

הסטודיו פתוח מהתחלה. חדר ההלבשה, הגינה ובמת הסרטים נפתחים אחרי 3, 6 ו־9 מפגשים שהושלמו, בהתאמה, על פני לפחות 2, 3 ו־4 ימים שונים. מפגשי למידה ומשימות לקוח נספרים; אין צורך ברצף ימים. לכל חדר עיצוב נפרד. משימת פתיחה כוללת ארבע עובדות שכבר תורגלו, מאפשרת עזרה ונשמרת באמצע. אין ציון מעבר או דרישת מהירות.

במשחק יש כרטיסיות טריקים ורמזים לפי התרגיל: עוגני 5 ו־10, תשע בתור עשר פחות אחת, הכפלה חוזרת ותרגילים הפוכים. דרכי חישוב מסייעות להגיע לתשובה; חזרה לאחר הפסקה ובימים נוספים מתרגלת שליפה. שימוש ברמז אינו נמדד כזכירה עצמאית.

בשמירה חדשה יש שישה בגדים ושישה רהיטים בחינם. פריטים רגילים עולים 10–20 מטבעות ופריטים מיוחדים 30–40. כל פריט שניתן או נקנה בגרסאות קודמות נשאר בבעלות השחקנית. גרסת מבנה השמירה היא 3; ייבוא גרסאות קודמות משמר את הבעלות ומוסיף את מבנה החדרים.

## פרופילים נפרדים ועיצוב במסך מלא

בכניסה בוחרים מי משחקת. לליאורי, לנועה ולכל שחקנית נוספת יש שמירה נפרדת: לימוד, מטבעות, רכישות, חדר, בגדים ואלבום. כפתור ״החלפה״ בראש המשחק מחזיר לבחירת פרופיל. אין חשבון או סנכרון בין מכשירים; כל הפרופילים נשמרים באותו דפדפן ובאותו מכשיר.

שמירה שנוצרה לפני עדכון הפרופילים מופיעה בשם ״השמירה הקיימת״. בוחרים ״למי שייכת השמירה?״ ומקשרים אותה לשם השחקנית. ההתקדמות אינה מתאפסת, והקובץ הישן נשאר בדפדפן כעותק שחזור. לאחר מכן אפשר ליצור פרופיל נוסף. ייצוא, ייבוא ואיפוס באזור ההורים חלים רק על הפרופיל שנבחר; כדאי לייצא כל פרופיל בנפרד.

בסטודיו ובמלתחה בוחרים ״עיצוב במסך מלא״. מגירת הפריטים נפתחת ונסגרת, ויש הגדלה, הקטנה וחיצים להזזת המבט. בטלפון אנכי החדר ממלא את השטח וניתן להזיז את המבט כדי להגיע לכל חלקיו; ״כל התמונה״ מראה את החדר כולו. ״חזרה למשחק״ או Escape יוצאים בלי לשנות את העיצוב.

משחק דפדפן בעברית לתרגול וזכירה של לוח הכפל (1–10): ליאורי מנהלת סטודיו לעיצוב ואופנה לכלבים.
כל לקוח מביא בקשה עיצובית ומקבץ קצר של תרגילים; אחר כך בוחרים לוק, מצלמים לאלבום ומעצבים את הסטודיו.

## לומדות וזוכרות

מסלול לימוד שמלמד לפני ששואלים: שש עובדות בשלושה זוגות. קודם רואים את התרגיל והתשובה ואומרים בקול,
מתרגלים עם התשובה גלויה, עושים פעולת עיצוב קצרה, ואז מנסים לזכור. בכל שאלה יש ״עוד לא זוכרת״.
אחרי עזרה התרגיל חוזר מאוחר יותר באותו שיעור. עובדות חדשות מצטרפות רק אחרי שהקודמות נזכרו לבד בשני ימים שונים.
אפשר לעצור באמצע — השיעור נשמר. הלוגיקה ב־`src/learning/learnPath.ts`.

## הפעלה מקומית

צריך Node.js (גרסה 18 ומעלה). בתיקיית הפרויקט:

```bash
npm install
```

```bash
npm run dev
```

ואז לפתוח בדפדפן את הכתובת שמופיעה (בדרך כלל http://localhost:5173).

## בדיקות

```bash
npm test
```

## בניית גרסה לפרסום

```bash
npm run build
```

התוצאה נמצאת בתיקייה `dist/` — אפשר להעלות אותה כמו שהיא לכל אחסון סטטי (GitHub Pages, Netlify וכו׳),
גם לתת־תיקייה. לבדיקה מקומית של הגרסה הבנויה:

```bash
npm run preview
```

## שמירה

כל ההתקדמות נשמרת בדפדפן ובמכשיר הנוכחיים בלבד (localStorage). אין שרת ואין חשבון.
גיבוי: ״ההתקדמות של ליאורי״ ← ״שמירה וגיבוי״ ← ייצוא קובץ. אפשר לייבא את הקובץ בדפדפן אחר.

## מבנה

- `src/learning/` — מנוע הלמידה: חזרות מרווחות (`scheduler.ts`), בניית מקבצים (`session.ts`), רמזים (`hints.ts`).
- `src/state/` — שמירה, אימות ותיקון (`save.ts`), מטבעות ורכישות (`economy.ts`), פעולות משחק (`game.ts`).
- `src/art/` — איורי SVG מקוריים: כלבים ובגדים, רהיטים, רקעים.
- `src/content/` — כלבים, פריטים, בקשות לקוח ופלטות.
- `src/screens/` — המסכים. `src/dev/Gallery.tsx` — עמוד פיתוח בלבד (`?gallery`) לבדיקת כל האיורים.

## פרסום (GitHub Pages)

הקובץ `.github/workflows/deploy.yml` בונה, מריץ בדיקות ומפרסם את המשחק בכל דחיפה לענף `main`.
פעם אחת צריך: לפרסם את המאגר ל־GitHub (ציבורי), ואז ב־Settings ← Pages ← Source לבחור „GitHub Actions”.
הכתובת: `https://<שם-המשתמש>.github.io/liori-studio/`

## טלפונים

- אייפון (Safari) ואנדרואיד (Chrome): המשחק מותאם לאורך ולרוחב ולאזורי המסך המוסתרים.
- הוספה למסך הבית: בתפריט ☰ ← „הוספה למסך הבית” יש הוראות לכל מכשיר.
- כל מכשיר שומר התקדמות משלו. באייפון, אפליקציה שנוספה למסך הבית שומרת בנפרד מספארי.
- תמונות וגיבויים נשמרים דרך תפריט השיתוף של הטלפון (או כהורדה, כשהוא לא זמין).
